# יומן עבודה יומי — Android

## מטרה

להפוך את רשימת ארבעת השבועות לסדר יום שימושי במכשיר נייד, בלי לשנות את מודל השיעורים או את סנכרון הענן.

## התנהגות

- „יום העבודה שלי” מציג את שבעת הימים הקרובים ובוחר את היום הנוכחי כברירת מחדל.
- אפשר לעבור יום קדימה או אחורה.
- מוצגים רק המפגשים שתאריך ההתחלה שלהם תואם ליום הנבחר, לפי סדר שעה.
- כל פעולה קיימת נשמרת: הגיע, נעדר, שולם וסיכום שיעור.
- תשלומים פתוחים ממשיכים להציג את רשימתם הנפרדת ללא סינון יום.

## עקביות

Windows נשאר עם תצוגת השבוע המלאה, כולל ניווט שבועי. שני הממשקים קוראים וכותבים לאותם נתוני שיעורים ומשתתפים בענן.

## אימות

`npm run verify:work-calendar` מוודא בחירת יום, ניווט, סינון מפגשים ושמירה על פעולות המעקב. הבדיקה נכללת ב־`release:check`.
