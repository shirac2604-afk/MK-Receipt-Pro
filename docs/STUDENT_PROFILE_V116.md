# כרטיס תלמיד מפורט — Android

## מה נוסף

לחיצה על תלמיד במרכז התלמידים פותחת כרטיס מידע מרוכז. הכרטיס מציג פרטי קשר, הורה ראשי, מצב תזכורות, מטרות ודגשים, שיעורים שהתקיימו, יתרה פתוחה ושיעורים קרובים.

## מקור הנתונים

כל הנתונים מגיעים ממסד הענן התחומי הקיים: `students`, `student_guardians`, `lessons` ו־`lesson_participants`. לא נשמר מידע תלמיד מקומי נוסף במכשיר.

## כלל הגבייה

"יתרה פתוחה" כוללת רק מפגשים עם `attendance = attended` ו־`payment = unpaid`. לכן שיעור עתידי או מפגש שבוטל אינם מוצגים כחוב.

## עקביות בין הפלטפורמות

Windows כבר מציג כרטיסי תלמיד עם פרטי לימוד, קשר, הורה ומחיר. מסך Android משלים כעת את כרטיס הסיכום והקישורים לעריכה וליומן על אותו מקור נתונים.

## אימות

`npm run verify:student-profile` בודק את טעינת נתוני השיעורים, חישוב היתרה, תכני הכרטיס והקישורים. הוא נכלל ב־`release:check`.
