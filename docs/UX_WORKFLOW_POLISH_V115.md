# שיפור חוויית שימוש — פעולות יומיות (v115)

## מטרה

לקצר את הדרך מהמסך הראשי לפעולות שמנהלות את יום העבודה: תלמידים, שיעורים, גבייה ודוחות.

## Android

- נוספו אריחי גישה מהירה לתלמידים, יומן שיעורים, גבייה ודוחות.
- היומן והגבייה מועברים למרכז התלמידים עם פרמטר ניווט מפורש, ולכן נפתחת הלשונית המתאימה ולא ברירת־המחדל.

## Windows

- דף הבית כולל כעת גישה שוות־משקל לתלמידים, יומן, גבייה, דוחות, לקוחות, גיבוי והיסטוריית קבלות.

## גבולות ואימות

- השינוי תצוגתי וניווטי בלבד; אין שינוי בנתונים או בחיבורי ענן.
- מאמת Android: `npm run verify:ux-workflow`.
- יש להריץ TypeScript ל־Android ול־Windows לפני מיזוג.
