# גיבוי ושחזור מקומי — Android

## מה נוסף

למסך הגדרות העסק נוסף „שחזור בטוח מגיבוי”. המשתמש בוחר קובץ JSON שנוצר על ידי האפליקציה.

## מודל בטיחות

- הקובץ חייב להיות בפורמט `MK_RECEIPT_MOBILE_BACKUP` בגרסה 1.
- מזהה העסק בגיבוי חייב להיות זהה לעסק המחובר.
- כל שורת נתונים נבדקת מול אותו `business_id`.
- הקלט מוגבל ל־10,000 רשומות לטבלה ונכתב בחבילות של עד 500 רשומות.
- השחזור משתמש ב־upsert עם `ignoreDuplicates`: הוא יוצר רק רשומות חסרות; רשומה קיימת אינה משתנה, נמחקת או נדרסת.

## כיסוי הקובץ

הגיבוי כולל נתוני עסק, לקוחות, הוצאות, קבלות, תלמידים, קבוצות, שיעורים, משתתפים ותזכורות. קובצי PDF ואסמכתאות לא נכללים, כי הם נמצאים באחסון הענן.

## עקביות בין הפלטפורמות

Windows כבר מספק מרכז גיבויים ושחזור מקומי. Android תומך כעת ביצירה, בדיקה ושחזור בטוח של קובץ הנתונים שלו, בלי לשנות את פעולת הגיבוי של Windows.

## אימות

`npm run verify:backup-restore` מוודא את פעולה השחזור, בידוד העסק, המניעה מדריסה, והגבלות הגודל. הבדיקה נכללת ב־`release:check`.
