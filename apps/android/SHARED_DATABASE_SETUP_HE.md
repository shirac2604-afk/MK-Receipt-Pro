# Foundation 3 — מסד נתונים משותף

הגרסה כוללת סכמת PostgreSQL מלאה לשכבה המשותפת של Windows ו Android.

## מה נבנה
- עסקים ומכשירים
- לקוחות
- הוצאות
- תבניות קבלה
- קבלות
- רצף מספור מרכזי
- Reservation אטומי למספר קבלה
- תיעוד Mutations ו Conflicts
- Cloud API Client ל Android
- קריאת לקוחות והוצאות ויצירתם מהענן

## חשוב
אין לשים Service Role Key בתוך Android או Windows.
האפליקציה משתמשת רק במפתח ציבורי וב Access Token של המשתמש.

## לפני חיבור לשרת אמיתי
צריך ליצור פרויקט PostgreSQL מנוהל, להפעיל את SQL שב cloud/sql,
ולהוסיף מדיניות Row Level Security כך שכל משתמש יוכל לגשת רק לעסק שלו.

השלב הבא הוא יצירת פרויקט הענן בפועל והגדרת RLS/Auth. עד אז קוד הלקוח קיים,
אך מסכי Android אינם שולחים מידע לשרת ייצור.
