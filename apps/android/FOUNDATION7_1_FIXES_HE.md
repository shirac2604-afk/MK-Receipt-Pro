# Foundation 7.1 — תיקוני קבלה וניווט Android

## שגיאות קבלה
האפליקציה מציגה כעת את השלב שבו ההנפקה נכשלה:
- רישום מכשיר
- הקצאת מספר
- RPC הנפקה בענן
- טעינת הקבלה לאחר ההנפקה

שגיאות Supabase מציגות code / message / details / hint כאשר קיימים.

## ניווט תחתון
סרגל הלשוניות משתמש ב SafeAreaInsets ולכן מורם מעל לחצני הניווט של Android.
הגובה וה padding התחתון מחושבים לפי המכשיר ולא לפי מספר קבוע.
