# MK Receipt Pro — Windows / Android Feature Parity

כלל מחייב: כל יכולת ב-Windows חייבת לקבל מימוש מקביל ב-Android.

## יכולות שנכללו בחוזה Android
- לוח ראשי
- הפקת קבלה
- היסטוריה, חיפוש וסינון קבלות
- ביטול קבלה
- לקוחות וזיהוי כפילויות
- הוצאות
- אסמכתאות להוצאות + מצלמה
- תבניות קבלה
- דוחות
- מרכז דיווחים
- יצוא מבנה אחיד
- חבילת סימולטור רשות המסים
- תיק רישום תוכנה
- גיבוי ושחזור
- Google Drive וסנכרון
- הגדרות העסק
- PIN ונעילה
- בדיקות בריאות מערכת
- אבחון
- QA

## כלל סנכרון
Windows ו-Android אינם מנהלים מספור עצמאי. לפני הפקת קבלות בפועל משני מכשירים,
יש להעביר את הקצאת מספרי הקבלה לשכבת סנכרון מרכזית שמונעת מספר כפול.

## מצב Foundation
השלד, הניווט, מודלי הליבה וחוזה התאימות הוקמו. השלב הבא הוא שכבת הנתונים
והסנכרון, ולאחריה חיבור המסכים לפעולות אמיתיות.
