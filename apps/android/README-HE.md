# MK Receipt Pro Android 1.0 — Foundation

זהו בסיס אפליקציית Android אמיתית ב-React Native / Expo, שנבנה במקביל לגרסת Windows 1.1.0.

## הפעלה
1. התקן Node.js ו-Android Studio.
2. בתיקיית הפרויקט:
   npm install
   npm run android

## מה כבר קיים
- ממשק RTL בעברית
- ניווט מותאם לטלפון
- ראשי / קבלות / לקוחות / הוצאות / עוד
- מודלי נתונים תואמי Windows
- חוזה Feature Parity מלא

## מה עדיין אינו מחובר
המסכים כרגע הם Foundation. הם עדיין אינם כותבים למסד הייצור ואינם מפיקים
קבלות אמיתיות. בכוונה לא חובר מספור קבלות מקומי כדי למנוע מספרים כפולים
בין Windows ל-Android.
