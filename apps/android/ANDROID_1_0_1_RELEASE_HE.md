# MK Receipt Pro Android 1.0.1

גרסה מלאה לבנייה.

תיקונים:
- בחירת לקוח קיים במסך קבלה חדשה.
- מילוי שם, טלפון ואימייל מהלקוח הנבחר.
- שמירת customer_id בקבלה.
- תיקון נעילת הנפקה לאחר ולידציה.
- תיקון fontWeight לא חוקי בדף הבית (850 -> 800).
- שומרת את package id הקיים ואת versionCode 3 לצורך עדכון מעל האפליקציה המותקנת.
