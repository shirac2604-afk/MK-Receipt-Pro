# MK Receipt Pro — Expenses V1

Development upgrade after the registration candidate.

Implemented foundation:
- Expenses database table (migration 008).
- Add/list expenses.
- Categories, supplier, date, amount, payment method and notes.
- Attach PDF/image receipt or invoice; a private copy is stored under app data.
- Open stored attachment from the expenses screen.
- Expense attachments are included in backup and restored with the database.
- New Expenses screen and sidebar entry.
