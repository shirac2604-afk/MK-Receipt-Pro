# 1.0.0-rc.17.21

## תוקן

- הכנת חבילת הסימולטור אינה דורשת עוד קובץ Preflight שלא נוצר בייצוא האמיתי.
- כאשר PREFLIGHT-RESULT.json חסר, הוא נוצר אוטומטית מתוך EXPORT-SUMMARY.json.
- נוספה בדיקה מוקדמת ומפורטת לקבצים חסרים.
- הודעות שגיאה מציגות את הקובץ או השלב שנכשלו במקום הודעה כללית.
- במסך רשות המסים נוסף כרטיס תקלה עם אפשרות להעתיק את פרטי התקלה ולפתוח את תיקיית ההפקה.
- כל תקלה ממשיכה להירשם ביומן התקלות ללא פרטי לקוחות.
