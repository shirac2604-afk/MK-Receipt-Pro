# יצירת מתקין Windows — גרסת RC

## לפני ההפעלה

- Windows 10 או 11 בגרסת 64 סיביות.
- Node.js 22 ומעלה.
- חיבור לאינטרנט בהתקנה הראשונה.
- יש להריץ מתוך תיקיית `MK-Receipt-Pro`.

## יצירת המתקין

פתחו PowerShell בתיקיית הפרויקט והריצו:

```powershell
npm install
npm run build:installer:win
```

הסקריפט מבצע לפי הסדר:

1. בדיקת גרסת Node.js.
2. בדיקת שלמות הפרויקט.
3. בדיקת TypeScript.
4. Build מלא של Electron ו-React.
5. יצירת מתקין NSIS ל-Windows.
6. אימות שקובץ `Setup.exe` אכן נוצר.

המתקין יישמר בתיקייה:

```text
release
```

שמו צפוי להיות:

```text
Maptehot-LaHatzlaha-1.0.0-rc.17.10-Setup.exe
```

## לפני שימוש אמיתי

גרסה זו היא Release Candidate. יש לבצע בדיקות עם נתוני דמה בלבד, לרבות PDF, גיבוי ושחזור, הסרה והתקנה מחדש, וחבילת רואה חשבון. אין להשתמש בה עדיין להפקת מסמכים רשמיים עד להשלמת הסימולטור והרישום מול רשות המסים.

## אזהרות npm audit

אין להריץ `npm audit fix --force` ללא בדיקה, משום שהפקודה עלולה לשדרג חבילות ראשיות ולשבור את ה-Build. אזהרות האבטחה ייבדקו בנפרד לפני גרסה 1.0 הסופית.
