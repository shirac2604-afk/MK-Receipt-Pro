# MK Receipt Pro 0.13.0

גרסת Dashboard, Help & Product Polish.

## הפעלה

```powershell
npm install
npm run check
npm start
```

## מה חדש

- דף בית סופי וממותג.
- פעולות מהירות לקבלה, חיפוש, דוחות, גיבוי ותקינות.
- מרכז עזרה עם חיפוש.
- סיור ראשוני לאחר השלמת אשף ההגדרה.
- קיצורי מקלדת והודעות מערכת אחידות.
- יומן תקלות נשאר כלי נפרד תחת התפריט.

גרסה זו עדיין מיועדת לפיתוח ובדיקות, ולא לשימוש במסמכים רשמיים.

## Installer & Release 0.14.2

גרסה זו מוסיפה תשתית מתקין Windows מקצועי עבור **מפתחות להצלחה**.

בדיקת הגדרות המתקין ללא התקנת חבילות:

```powershell
npm run check:installer
```

יצירת מתקין:

```powershell
npm install
npm run dist:win
```

המתקין יישמר בתיקיית `release`. נתוני העסק נשמרים בנפרד ואינם נמחקים בהסרת התוכנה.
