# Feature Freeze — Version 1.0

גרסה `1.0.0-rc.17` נעולה מבחינת יכולות.

מותר להכניס לפני Version 1.0 רק:

- תיקון אובדן נתונים, מספור, PDF, גיבוי או שחזור.
- תיקון שנדרש בעקבות הסימולטור הרשמי של רשות המסים.
- תיקון קריסה או בעיית אבטחה.
- תיקון UX קטן שאינו משנה תהליך עסקי או מבנה נתונים.

לא יתווספו לגרסה 1.0:

- צ'קים, כרטיסי אשראי או אמצעי תשלום "אחר".
- סליקה.
- חשבוניות מס.
- הנהלת חשבונות או מלאי.
- מודול תלמידים, שיעורים או חומרי הוראה.
- מסכי ניטור ושדרוגים שאינם נדרשים לבדיקה הנוכחית.
