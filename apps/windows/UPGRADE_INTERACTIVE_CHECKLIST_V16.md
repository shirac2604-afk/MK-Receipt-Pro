# 1.1.0-dev.16 — Interactive self-filing checklist

- Adds a year-specific interactive checklist in the reporting center.
- Checklist state is stored locally per reporting year.
- Tasks cover VAT turnover review, cancelled receipts, expenses, missing expense documents, external documents, and annual package creation.
- Includes reset control and completion count.
- Checklist state is organizational only and is not accounting data or tax approval.
