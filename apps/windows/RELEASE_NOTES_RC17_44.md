# גרסה 1.0.0-rc.17.44

תיקון עומק לפי דוח הסימולטור והמפרט החזותי הרשמי:

- תוקנה טעות BiDi: סדר התווים הפיזי בקבצים הוא A000/A100/C100/D120/B100/B110/Z900.
- קבוע המערכת הפיזי הוא &OF1.31&.
- רשומות הסיכום ב-INI הן B100/B110/C100/D120.
- חבילת הנהלת החשבונות מסומנת ככפולה (1013=2) עם איזון ברמת תנועה (1014=1).
- נוספה הפרדה בין קודי הקובץ הפיזיים לבין שמות הסוגים הלוגיים בממשק.
- בדיקות ה-byte/preflight עודכנו לבדוק את סדר הבתים בפועל ולא טקסט שעבר היפוך RTL.
