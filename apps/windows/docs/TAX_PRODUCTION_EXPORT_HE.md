# ייצוא אמיתי לרשות המסים

1. פתח את התוכנה המותקנת ובדוק שבמסך פרטי העסק מופיעים הנתונים הרשמיים.
2. הפק קבלות בדיקה דרך התוכנה.
3. פתח רשות המסים, בחר טווח תאריכים ולחץ הפקת מבנה אחיד.
4. בדוק את OPEN-FORMAT-PRODUCTION-AUDIT.json. השדה fixture חייב להיות false והשדה source חייב להיות application_database.
5. העלה לסימולטור רק לאחר שה-Preflight תקין.

הפקודה tax:prepare-simulator ממשיכה לייצר 1,000 קבלות דמה לצורך בדיקות עומס בלבד; היא אינה ייצוא העסק האמיתי.
