# RC 17.7 — עיצוב קבלה בעמוד אחד

- שוליים הוקטנו ל-10 מ״מ.
- הכותרת והלוגו הוקטנו ונבנו מחדש.
- פרטי העסק שולבו בכותרת במקום אזור נפרד ארוך.
- פרטי הלקוח ומעמד העסק מוצגים זה לצד זה.
- פרטי התשלום והסכום מוצגים בשורה אחת.
- הכותרת התחתונה נדחפת לתחתית העמוד ללא יצירת עמוד נוסף.
- ט.ל.ח נשמר בתחתית הקבלה.
