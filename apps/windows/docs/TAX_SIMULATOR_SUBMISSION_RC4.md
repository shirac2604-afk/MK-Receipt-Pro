# חבילת העלאה לסימולטור — RC4

לאחר הפקת המבנה האחיד ובדיקת Preflight, ניתן ליצור חבילת הכנה לסימולטור.

החבילה כוללת:

- `INI.TXT`
- `BKMVDATA.TXT`
- `REPORT-2.6.html`
- `REPORT-5.4.html`
- `PREFLIGHT-RESULT.json`
- `EXPORT-SUMMARY.json`
- `SUBMISSION-MANIFEST.json`
- הוראות עבודה
- תיקייה ריקה לשמירת הדוח הרשמי שמחזיר הסימולטור

החבילה אינה נשלחת אוטומטית ואינה מהווה אישור או רישום. לאחר הפעלת הסימולטור יש לשמור את הפלט הרשמי בתיקיית `SIMULATOR-RESULTS` ולצרפו לבקשת הרישום.
