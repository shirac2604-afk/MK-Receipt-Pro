# רשות המסים — ממשק פתוח 1.31 (RC2)

נוסף מודול נגיש צעד אחד מהתפריט הראשי. הוא מפיק לפי טווח תאריכים:

- `INI.TXT` ברשומה קבועה וברשומות סיכום.
- `BKMVDATA.TXT` הכולל `BKMVDATA.TXT`.
- רשומות A100, C100, D120 ו-Z900.
- דוח HTML להדפסה לפי סעיף 2.6.
- דוח HTML להדפסה לפי נספח 5.4.
- `EXPORT-SUMMARY.json` לבדיקת התאמה פנימית.

## מגבלות RC2

- מספר רישום התוכנה בשדה 1006 הוא ערך זמני `00000001` עד לקבלת מספר רשמי.
- חובה להעביר את הקבצים בסימולטור רשות המסים ולתקן כל אי-התאמה לפני הגשה.
- דוחות 2.6 ו-5.4 מופקים כ-HTML מוכן להדפסה; בשלב הבא יתווסף PDF קבוע.
- ביט ופייבוקס ממופים בשלב זה לקוד אמצעי תשלום 9 — אחר.
- המערכת מפיקה קבלות בלבד, ולכן גרעין הרשומות הוא C100/D120.
