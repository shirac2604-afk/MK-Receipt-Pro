# תיקון קודי רשומות לפי הסימולטור — RC 17.32

הסימולטור הרשמי זיהה שקודי הרשומות נדרשים בסדר אות–מספרים.

## קודים תקינים
- `A000` — רשומה מרכזת בקובץ `INI.TXT`
- `A100` — רשומת פתיחה בקובץ `BKMVDATA.TXT`
- `C100` — כותרת מסמך
- `D120` — פרטי תקבול
- `Z900` — רשומת סגירה

גם רשומות הסיכום ב־`INI.TXT` משתמשות בקודים `C100` ו־`D120`.

התיקון הוחל על מנוע הייצוא, מחולל 2,002 הרשומות, בדיקות Preflight, ביקורת כותרות, ביקורת בתים, דוחות ותיק ההגשה.
