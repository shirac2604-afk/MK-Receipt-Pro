# ביקורת נתיבי OPENFRMT — RC13

## הכללים שיושמו

1. תחת יעד השמירה נוצרת ספרייה בשם `OPENFRMT`.
2. מתחתיה נוצרת ספריית עסק במבנה `XXXXXXXX.YY`:
   - שמונה הספרות הראשונות של מספר העוסק, ללא ספרת הביקורת.
   - נקודה.
   - שתי הספרות האחרונות של שנת ההפקה.
3. ספריית ההפקה נוצרת במבנה `MMDDhhmm` בלבד.
4. כאשר קיימת כבר הפקה באותה דקה, ההפקה החדשה משתמשת בערך הדקה העוקבת. לא נוצרת סיומת `-1`.
5. גם במעבר שעה, יום, חודש או שנה, ערך הדקה מתקדם כתאריך אמיתי.
6. שנת ספריית העסק נשארת שנת מועד ההפקה המקורי, גם במקרה נדיר שבו דחיית הדקה עוברת לחצות.
7. בתיקיית ההפקה נשמרים `INI.TXT` ו־`BKMVDATA.TXT`.
