# RC10 — ביקורת INI.TXT, A100 ו-Z900

## מטרה
הפרדה בין תקינות מבנית לסימולטור לבין מוכנות להגשה רשמית.

## בדיקות שנוספו
- אורך A000: 466 תווים.
- אורך A100: 95 תווים.
- אורך Z900: 110 תווים.
- התאמת מספר העוסק בין שלוש הרשומות.
- התאמת המזהה הראשי בן 15 הספרות.
- התאמת סך הרשומות ב-A000 וב-Z900.
- קבוע מבנה `&1.31OF&`.
- תוכנה רב-שנתית: קוד 2.
- מערכת ללא מודול הנהלת חשבונות: קוד 0.
- תאריכי חיתוך, תאריך ושעת הפקה.
- עברית: קוד שפה 0 ו-ISO-8859-8 קוד 1.
- מטבע ILS ושיטת כיווץ.

## מספר רישום ופרטי יצרן
הערכים ניתנים להגדרה בעת Build באמצעות:
- `MK_TAX_SOFTWARE_REGISTRATION_NUMBER`
- `MK_TAX_MANUFACTURER_NUMBER`
- `MK_TAX_MANUFACTURER_NAME`
- `MK_TAX_SOFTWARE_NAME`
- `MK_TAX_SOFTWARE_EDITION`

כאשר מספר הרישום הוא `00000000` או מספר היצרן הוא `000000000`, הקובץ יכול לשמש להכנה ולבדיקה מבנית, אך מסומן כלא מוכן להגשה רשמית עד לקבלת הנחיה/מספר אמיתי.
