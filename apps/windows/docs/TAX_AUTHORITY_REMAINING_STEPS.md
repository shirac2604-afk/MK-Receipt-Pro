# מה נשאר מול רשות המסים

1. בירור הערך הנכון לשדה 1006 עבור תוכנה חדשה שטרם נרשמה.
2. אימות מקצועי של מיפוי Bit ו-PayBox לקוד 9 ברשומת D120.
3. יצירת הקבצים מתוך Build אמיתי ב-Windows.
4. בדיקה חזותית והדפסה של דוחות 2.6 ו-5.4.
5. העלאה לסימולטור הרשמי ושמירת דוח תקין.
6. תיקון כל שגיאה שהסימולטור יחזיר.
7. בדיקה של יועץ מס/רואה חשבון ומומחה מערכות מידע.
8. מילוי הבקשה הדיגיטלית וצירוף המסמכים.

תעודת הרישום אינה מהווה אישור לנכונות ביצועי התוכנה או לעמידתה בהוראות ניהול פנקסים.
