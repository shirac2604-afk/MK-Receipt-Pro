# התאמת שמות הקבצים לסימולטור — גרסה 1.0.0-rc.17.37

הסימולטור הרשמי מבקש שני קבצים ישירים:

- `INI.TXT`
- `BKMVDATA.TXT`

בגרסה זו הוסרו שמות הפלט הישנים `TXT.INI`, `TXT.BKMVDATA` ו־`BKMVDATA.zip` מתהליך הסימולטור.
קובץ הנתונים אינו מכווץ. חבילת העזר `SIMULATOR-SUBMISSION.zip`, אם נוצרת, היא מעטפת מקומית בלבד ואינה הקובץ שמעלים בשדה BKMVDATA באתר.
