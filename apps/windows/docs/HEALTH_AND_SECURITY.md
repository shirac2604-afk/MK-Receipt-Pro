# Health & Security 0.12.0

- מרכז תקינות נפרד בודק SQLite, רצף קבלות, קובצי PDF, גיבויים ושטח אחסון.
- יומן התקלות הוא מסך נפרד תחת כלים מתקדמים ואינו מוצג בדף הבית.
- יומן התקלות אינו מיועד לשמור פרטי לקוחות.
- PIN ונעילה אוטומטית משתמשים בהגדרות שנקבעו באשף.
- לאחר חוסר פעילות, התוכנה ננעלת ומבקשת PIN.
