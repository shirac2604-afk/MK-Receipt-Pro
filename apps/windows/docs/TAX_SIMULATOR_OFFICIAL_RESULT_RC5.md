# ייבוא תוצאת הסימולטור הרשמי — RC5

לאחר הרצת קובצי המבנה האחיד בסימולטור הרשמי, המשתמשת מצרפת את דוח ה-PDF שהופק ומעתיקה ממנו את תוצאת הבדיקה ואת כמויות הרשומות.

המערכת:
- שומרת עותק של דוח ה-PDF המקורי בתיק ההגשה.
- מחשבת SHA-256 לדוח.
- משווה את סך הרשומות וכמויות A100, C100, D110, D120, B100, B110, M100 ו-Z900 לנתוני ההפקה.
- יוצרת `OFFICIAL-SIMULATOR-RESULT.json`.
- מעדכנת את `SUBMISSION-MANIFEST.json`.
- מסמנת במפורש אם נמצאו אי-התאמות.

המערכת אינה מנסה לבצע OCR לדוח חזותי בעברית. הנתונים מועתקים מהדוח על ידי המשתמשת ונבדקים מול נתוני המקור, כדי למנוע פענוח אוטומטי שגוי.
