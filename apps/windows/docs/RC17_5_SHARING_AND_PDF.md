# RC 17.5 — שיתוף קבלה וליטוש חלון/PDF

- נוספה פתיחת הודעת מייל מוכנה ללקוח לאחר הפקת קבלה.
- נוספה פתיחת שיחת WhatsApp מוכנה ללקוח לאחר הפקת קבלה.
- מטעמי אבטחה ומגבלות Windows, קובץ ה-PDF מסומן בסייר הקבצים לצירוף ידני להודעה.
- תפריט Electron/Windows העליון הוסר; כפתורי המזעור, ההגדלה והסגירה נשארו.
- הכיתוב ט.ל.ח נוסף בתחתית כל קבלת PDF, כולל מסמך ביטול.
