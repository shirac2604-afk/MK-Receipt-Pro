# ביקורת בתים למבנה האחיד — RC11

הבדיקה מאמתת את קובצי `INI.TXT` ו-`BKMVDATA.TXT` ברמת הבתים ולא רק לאחר פענוח לטקסט.

## בדיקות

- אין BOM של UTF-8.
- כל שורה מסתיימת ב-CRLF (`0D 0A`).
- אין CR או LF בודדים.
- כל תו הוא ASCII או אות עברית בטווח ISO-8859-8 (`E0`–`FA`).
- אורך כל רשומה בבתים תואם למפרט.
- שדות נומריים שנבדקו מכילים ספרות בלבד ומרופדים באפסים משמאל.
- שדות אלפאנומריים עתידיים שנבדקו מרופדים ברווחים מימין.
- שדות מותנים שאינם בשימוש ב-D120 מאופסים.
- קיימת דוגמת עברית ממשית בקובץ הבדיקה.

## תוצר

בכל ייצוא נוצר `OPEN-FORMAT-BYTE-AUDIT.json`. בנתוני הסימולטור נוצר גם `BYTE-LEVEL-AUDIT.json`.

בדיקה זו אינה מחליפה את הסימולטור הרשמי של רשות המסים.
