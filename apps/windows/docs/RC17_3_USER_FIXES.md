# תיקוני שימוש RC 17.3

## לוגו
הלוגו הממותג נטען באמצעות נתיב יחסי בתוכנה. בקבלת PDF נעשה שימוש קודם בלוגו שהוגדר באשף העסק, ובאין לוגו מוגדר נעשה שימוש בלוגו המובנה.

## לקוחות
לקוח חדש נשמר אוטומטית בטבלת customers לאחר הפקת קבלה. במסך קבלה חדשה קיימת רשימת לקוחות שמורים הממלאת את השם, הטלפון והאימייל.

## קבלות PDF
קבלות נשמרות בתיקייה:
Documents/מפתחות להצלחה/קבלות/YYYY/MM

קובץ HTML נוצר זמנית רק לצורך הדפסת Chromium ונמחק מיד. תיקיית הקבלות מכילה PDF בלבד.

## חבילת רואה חשבון
החבילה נוצרת בתיקייה מסודרת, כוללת CSV, סיכום שנתי, README ותיקיית קבלות-PDF. קבלות חסרות נוצרות מחדש לפני הייצוא, והתיקייה נפתחת אוטומטית בסיום.
