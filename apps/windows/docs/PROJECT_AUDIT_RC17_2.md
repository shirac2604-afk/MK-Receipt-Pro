# דוח Audit לפרויקט — 1.0.0-rc.17.2

## תוקן

- `moduleResolution` תואם TypeScript 5.8.
- תלויות ננעלו לגרסאות קבועות במקום `latest`.
- נתיב הפלט במצב `dev` תוקן.
- טיפוסי תוצאת הסימולטור נוספו ל-Preload.
- קודי שגיאה חסרים נוספו/מופו.
- גישת IPC לשולח ללא `senderFrame` הוקשחה.
- שדות אופציונליים נבנים ללא ערכי `undefined` מפורשים.
- טיפוסי Health, Settings, PDF ו-QA תוקנו.
- בדיקות Installer עודכנו כך שלא ידרשו גרסה ישנה קשיחה.
- מספרי הגרסה הפנימיים ו-Build metadata עודכנו.

## אומת סטטית

- כל ה-imports היחסיים מצביעים לקבצים קיימים.
- קיימים קובצי Electron, Renderer, Database, PDF, Backup ו-Tax Open.
- הגדרות האבטחה המרכזיות קיימות.
- App ID נשאר קבוע.

## מגבלת סביבת הבדיקה

לא ניתן לבצע `npm install` בסביבה זו בגלל מאגר חבילות פנימי שאינו מכיל את `@types/node`. לכן Build מלא עם חבילות Electron/React צריך לרוץ במחשב Windows של המשתמשת.
