# מפתחות להצלחה 1.0.0-rc.17.3

## תיקונים מרכזיים

- הלוגו הממותג נטען בנתיב תקין גם בהתקנה מקומית.
- הלוגו שנבחר בהגדרת העסק מופיע בקבלות PDF.
- לקוחות חדשים נשמרים אוטומטית וניתנים לבחירה בקבלה הבאה.
- קבלות נשמרות כ-PDF בתיקיות מסודרות: מסמכים/מפתחות להצלחה/קבלות/שנה/חודש.
- קובצי HTML המשמשים ליצירת הקבלה הם זמניים ונמחקים; תיקיית הקבלות מכילה PDF בלבד.
- חבילת רואה החשבון נוצרת בתיקייה מסודרת, מכילה CSV וקבלות PDF, ונפתחת אוטומטית בסיום.
- קבלות ישנות שחסר להן PDF נוצרות מחדש לפני יצירת חבילת רואה החשבון.
