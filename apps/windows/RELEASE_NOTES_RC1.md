# מפתחות להצלחה — 1.0.0-rc.1

## מהדורה
Release Candidate 1 — Functional QA

## הושלם
- הרצת 27 בדיקות אוטומטיות ומבניות.
- אימות SQLite, Transactions ומספור.
- אימות חיפוש, ביטול, דוחות וגיבוי.
- אימות מרכז התקינות, האבחון ומרכז QA.

## עדיין נדרש
- Build מלא לאחר `npm install`.
- מתקין Windows ובדיקות התקנה.
- בדיקות PDF חזותיות והדפסה.
- שחזור מלא על מחשב נקי.

## אזהרה
גרסה זו היא Release Candidate ואינה מיועדת עדיין לקבלות רשמיות.

## Stress Tests

- נבדקו 1,000, 10,000, 50,000 ו-100,000 קבלות.
- לא נמצאו מספרים כפולים.
- חיפוש משולב ודוחות שנתיים עברו את יעדי הביצועים ברמת SQLite.
- גיבוי מסד עבר דחיסה ואימות SHA-256.
- בדיקות PDF וגיבוי מלא עם אלפי מסמכים ממתינות למחשב Windows.

## Failure QA

נוספו 14 בדיקות כשל אוטומטיות. כולן עברו ללא חסימת שחרור אוטומטית. בדיקות ניתוק חשמל, כונן מלא, ניתוק USB/Google Drive וסגירת Electron דרך Task Manager נשארו לביצוע ידני על Windows.
