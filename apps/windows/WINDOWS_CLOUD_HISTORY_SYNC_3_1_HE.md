# Windows Cloud 3.1 — Receipt History Sync

- היסטוריית הקבלות ב-Windows נטענת מ-Supabase כאשר חשבון הענן מחובר.
- קבלות שהופקו ב-Android מופיעות ב-Windows.
- PDF נפתח מ-receipt-documents באמצעות Signed URL פרטי.
- שיתוף מייל/WhatsApp מוריד עותק זמני של ה-PDF לענן למחשב וממשיך את תהליך השיתוף הקיים.
- כאשר הענן מנותק, Windows חוזר להיסטוריה המקומית.
- ביטול קבלה ממסך היסטוריה בענן חסום זמנית כדי שלא יתבצע ביטול מקומי על מזהה ענן.
