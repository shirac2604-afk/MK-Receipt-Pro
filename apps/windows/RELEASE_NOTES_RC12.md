# מפתחות להצלחה 1.0.0-rc.13

## חדש
- הצלבה אוטומטית בין TXT.INI, TXT.BKMVDATA, דוח 2.6 ודוח 5.4.
- יצירת OPEN-FORMAT-SUMMARY-AUDIT.json בכל ייצוא.

## תוקן
- דוח 5.4 מסכם רק רשומות נתונים (100C ו-120D), בהתאם למבנה הדוגמה, ואינו כולל 100A/900Z בסך הרשומות המודפס.
- בדיקת הבתים של TXT.BKMVDATA מבוצעת לפני מחיקת הקובץ הלא-מכווץ.

## חשוב
- בדיקות פנימיות אינן מחליפות את הסימולטור הרשמי של רשות המסים.
