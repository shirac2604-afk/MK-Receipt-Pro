# MK Receipt Pro — 1.1.0-rc.1

Release Candidate לבדיקה לפני מתקין Windows סופי.

בדיקת מקור:
`npm run check:release-candidate`

הרצה לבדיקה:
`npm install`
`npm start`

בניית מתקין Windows:
`npm run release-candidate:installer`

הערה: לפני גרסת 1.1.0 הסופית יש להחליף את Google OAuth credential שנחשף במהלך הפיתוח.
