# הכנת קובצי בדיקה לסימולטור רשות המסים

גרסה: 1.0.0-rc.17.21

## הפקת חבילת בדיקה

פתח PowerShell בתיקיית הפרויקט והריץ:

```powershell
npm install
npm run tax:prepare-simulator
```

התוצרים ייווצרו בתיקייה:

```text
test-output\tax-open-simulator-fixture
```

התיקייה אמורה לכלול בין היתר:

- `TXT.INI`
- `TXT.BKMVDATA`
- `BKMVDATA.zip`
- דוח Preflight
- דוחות הביקורת למבנה, לקידוד, לסיכומים ולארכיב

## לפני העלאה לסימולטור הרשמי

1. ודא שכל בדיקות ה־Preflight הסתיימו ללא שגיאות.
2. אל תשתמש בנתוני לקוחות אמיתיים בקובץ הבדיקה.
3. העלה לסימולטור רק את הקבצים הנדרשים לפי הוראות רשות המסים.
4. שמור את דוח התוצאה הרשמי שהסימולטור מפיק.
5. אין לראות בבדיקות המקומיות אישור של רשות המסים.

## נקודות שעדיין דורשות הכרעה רשמית

- מספר הרישום שיש להזין בעת בדיקת תוכנה חדשה שטרם נרשמה.
- מיפוי Bit ו־PayBox בקוד אמצעי התשלום במבנה 1.31.
