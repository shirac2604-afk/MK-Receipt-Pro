# מפתחות להצלחה 1.0.0-rc.17.10

## חדש

- תהליך אחד לבניית מתקין Windows: `npm run build:installer:win`.
- בדיקות מוקדמות לגרסת Node.js, שלמות הפרויקט ו-TypeScript.
- אימות אוטומטי שקובץ Setup נוצר בתיקיית `release`.
- מדריך עברי לבניית המתקין ולתחילת בדיקות RC.

- אין שינוי במספור הקבלות, במסד הנתונים, בקובצי PDF או בייצוא לרשות המסים.
- Feature Freeze נשמר.
