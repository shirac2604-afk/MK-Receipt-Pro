# מפתחות להצלחה — להתחיל כאן

גרסה: `1.0.0-rc.17`

זוהי גרסת מועמדת לבדיקה מלאה. היא אינה מאושרת עדיין על ידי רשות המסים ואינה מיועדת בשלב זה להפקת מסמכים רשמיים ללקוחות.

## 1. הכנת סביבת העבודה

ב-PowerShell מתוך תיקיית הפרויקט:

```powershell
npm install
npm run check:rc-candidate
npm run typecheck
npm run build
```

## 2. יצירת מתקין Windows

```powershell
npm run rc:build:win
```

המתקין יופיע בתיקיית `release`.

## 3. סדר הבדיקה

1. התקנה על Windows.
2. הגדרת עסק עם נתוני דמה בלבד.
3. הפקת 30 קבלות דמה רצופות.
4. פתיחת PDF והדפסה ל-Microsoft Print to PDF.
5. ביטול שתי קבלות ובדיקת מסמכי הביטול.
6. בדיקת חיפוש ודוחות.
7. יצירת גיבוי ושחזור על התקנה נקייה.
8. הפקת FORMAT OPEN ו-2,002 רשומות.
9. בדיקת דוחות 2.6 ו-5.4 ב-PDF ובהדפסה.
10. העלאת הקבצים לסימולטור הרשמי של רשות המסים.

## 4. כללי בטיחות

- אין להשתמש בנתוני לקוחות אמיתיים בתקופת הבדיקה הראשונית.
- אין להציג את התוכנה כמאושרת או רשומה לפני קבלת תעודה.
- אין להשתמש במספר רישום מומצא בשדה 1006.
- כל תקלה נרשמת בקובץ `docs/RC_ISSUE_LOG.csv`.
